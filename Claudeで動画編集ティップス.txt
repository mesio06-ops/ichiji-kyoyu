# Claudeで動画を作る方法 まとめ（スレッドのTips網羅版）

## 前提：Claudeにできること・できないこと

Claude自体は、画像生成AIのように絵や映像を直接描くことはできません。ただし次の3つができるため、組み合わせれば企画から完成まで回せます。

- **コードで映像を作る**：HTML/JS/SVGなどで描画するモーショングラフィックスは単体で作れます。
- **見て判断する**：生成された画像や動画をコマ単位で確認し、採用・不採用を決められます。
- **他のツールを操作する**：Claude CodeからCLI、MCP、API、PC操作を通じて外部ツールを動かせます。

「Claudeに他のツールを遠隔操作させて、制作を半自動化する」と考えると分かりやすいです。

---

## 方法①：Claude単体でコードから映像を作る（いちばん手軽）

- **Opus 5.5に「動画作って」と言うだけ**でも作れます（スレ主が実際に試して成功）。
- より良い結果を出すには、「あなたはモーションデザイナーです。モーショングラフィックス動画を作成して」と役割を与えてから詳細を指示します。ベクター系の映像をJSでレンダリングしてくれます。
- 使われる技術は、HTML、JavaScript、Canvas、SVG、GSAP、React、TypeScriptなどです。アプリのUIをコードで書くのと同じ要領です。
- **Remotion**（ReactでWeb上で動画を作るフレームワーク）や**Hyperframes**と組み合わせると、そのまま動画ファイルとして書き出せます。
- 静止画が欲しいときは、HTMLで作らせてから画像に変換する方法があり、これもClaude単体で完結します。
- **限界**：キャラクターアニメや実写風の映像は作れません。これらは次の外部の生成AIに任せます。

---

## 方法②：素材の生成を外部AIに任せる

### 画像
- **Codex CLI**：Claude Codeから「Codex CLIの/imagegenで画像を作れるようにして」と頼んで連携させます。Claude CodeにCodexをインストールしておくと便利です。
- **ChatGPT**：Chromeを操作させて生成し、回収させます。APIでつなぐ方法もありますが有料です。
- **Gemini**：APIで呼び出します。
- **ローカル生成**：ComfyUIをMCP経由で動かします。

### 動画
- **Higgsfield**：課金したうえでMCPでつなぎます。
- **Sora、Omni、Seedance、Wan**など：APIやCLIで接続します。
- **ローカルの動画生成AI**：Claude Codeにプロンプトを書かせて生成を回させます。

### 音声・音楽
- **VOICEVOX**、**irodori TTS**：ナレーションや読み上げに使います。
- **ElevenLabs**：音声生成に使います。
- **ローカル生成**：音楽もローカル環境で作れます。
- MVを作る場合は、曲を自分で用意する方法もあります（約5往復で完成した例あり）。

### ネットから素材を拾う
- ジャンルによっては、素材を生成せずにネットから自動で拾って配置させる方法もあります。
- ※著作権やライセンスには必ず注意してください。

## 方法③：編集をClaudeにやらせる

| ツール | やり方・特徴 |
|---|---|
| **ffmpeg** | コマンドで動画を操作するツール。これが入っていれば、AIエージェントがカット、結合、合成などを自由に行えます。 |
| **Remotion / Hyperframes** | プラグインをつなげて「いい感じに編集して」と頼みます。 |
| **DaVinci Resolve** | Claudeが書いたスクリプトを1クリックで実行すると、カット・曲・歌詞が並んだ状態で開きます。フィルター操作も可能です。 |
| **CapCut** | さらに凝りたい場合、CodexのComputer Useで操作させます。 |
| **Filmora** | コミュニティ製のMCPが公開されています。 |
| **YMM4（ゆっくりMovieMaker4）** | プロジェクトの中身がすべてJSONなので、字幕の翻訳や文言チェックができます。 |
| **AviUtl2** | コマンドラインを直接触らせると、いろいろなことができそうです。 |

撮影した動画を編集するだけなら、**Claude Code × ElevenLabs × ffmpeg**の組み合わせが安くて速いです。

## 運用・ワークフローのコツ

- **人間はダメ出し係**：企画、プロンプト作成、生成、採否判断、編集までClaudeに任せ、人間は確認と修正指示に回ります。
- **環境構築もClaudeに任せる**：「CLIかMCPで接続できる動画生成サービスを1つ契約したので使えるようにして」「動画制作に必要なツール一式をインストールして」と頼めば、セットアップまでやってくれます。
- **Chromeを軸にする**：ブラウザ操作エージェントを使えば、アプリ版からでもターミナル版からでも、ChatGPTなどのWebサービスを操作させられます。
- **Skill化する**：よく使う手順をSkillにまとめておくと、安く速く回せます。
- **自律作業を管理する**：長時間の作業では、進捗確認用の簡単なHTMLダッシュボードを毎回用意させるのがおすすめです。Claudeからの質問にはSlack、Discord、Telegramなどで非同期に回答します。
- **大量の素材も扱える**：コマ単位でチェックさせる運用が有効です。
- **迷ったらClaudeに聞く**：自分のPC環境で何ができるかは、Claude本人に聞くのがいちばん早いです。

## 目的別のおすすめ構成

- **とりあえず試したい**：Opus 5.5に「モーショングラフィックス動画を作って」と頼む。
- **解説・図解系の動画**：Remotion＋VOICEVOX（またはElevenLabs）。
- **MVやAI映像作品**：画像生成（Codex/ChatGPT）→動画生成（Higgsfield/Seedanceなど）→DaVinciかffmpegで編集。
- **撮影動画の編集**：Claude Code＋ffmpeg＋ElevenLabs。
- **お金をかけずに全部ローカルで**：ComfyUI（MCP）＋ローカル動画生成＋irodori TTS＋Remotion。
