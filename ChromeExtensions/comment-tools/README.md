# コメント取得ツール

「コメント取得」フォルダーにあった32個のブックマークレットを、Chrome拡張機能のボタンに移しました。

| サイト | 機能数 |
| --- | ---: |
| X・Twitter | 12 |
| はてブ | 3 |
| Togetter・Posfie | 6 |
| はてな匿名ダイアリー | 2 |
| ヤフコメ | 9 |

## 初回の導入

1. Chromeのアドレス欄に `chrome://extensions` を入力します。
2. 右上の「デベロッパー モード」を有効にします。
3. 「パッケージ化されていない拡張機能を読み込む」を押します。
4. `F:\youtube\tools\comment-tools\extension` フォルダーを選びます。
5. Chrome右上の拡張機能一覧から「コメント取得ツール」をピン留めします。

パッケージの追加や、サーバーの起動は不要です。

## 使い方

1. 対象サイトのページを開きます。
2. Chrome右上の「コメント取得ツール」のアイコンを押します。
3. ページ右上に表示される一覧で、実行する機能を押します。

開いているサイトの分類が最初に選択されます。「すべて」で全32機能を確認できます。対象サイトが違う機能はボタンが無効になります。検索欄で「ユーザー名」「csv」などを探せます。

取得条件、読み込み、整形、ファイル名、新規タブの表示は、元の処理を引き継いでいます。ツールの「開始しました」は処理開始の表示です。取得の進行と結果は、元の処理がページに表示するメッセージやダウンロードで確認してください。取得中にページを再読み込みしたりタブを閉じたりすると、処理も止まります。

## 今後の修正

AIに「コメント取得ツールのXポスト取得を修正してください」のように依頼してください。

- 機能名とファイルの対応表：`機能一覧.md`、`extension/tools.json`
- 各ボタンの名前・対象サイト・処理：`extension/scripts/` 内のJavaScriptファイル（名前・対象サイトを変える際は `tools.json` にも反映します）
- ページ内のボタン一覧：`extension/toolbar.js`
- 拡張機能の起動処理：`extension/background.js`
- 取り込み時の原文：`extension/元の処理.json`

処理を直した後は `chrome://extensions` の「コメント取得ツール」の再読み込みボタンを押し、対象ページでツールのアイコンを押して開き直します。Chromeのブックマーク編集は不要です。既存ブックマークと書き出し元のHTMLは保持しています。

今回の移行では元のコードを保持しています。サイトの仕様変更で動作が止まっている処理の修正は、該当ファイルで行います。

## 権限

権限は「クリックしたタブへの一時アクセス」と「ローカルのスクリプト実行」の2つです。ツールを開くだけでは、取得処理を実行しません。取得ボタンを押すと、元の処理に含まれる各サイトへのアクセスや保存を行います。

Chrome公式仕様：<https://developer.chrome.com/docs/extensions/reference/api/scripting>

## 取り込み用スクリプト

`import-bookmarks.mjs` はHTMLから「コメント取得」フォルダー内だけを抽出します。既存ファイルがある場合は、標準動作では停止します。初期生成の修正に使う `--refresh-generated` も、処理ファイルの編集を検知した場合は停止します。

`元の処理.json` は比較用の記録です。修正後に再取り込みする必要はありません。
